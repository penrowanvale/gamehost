# SERVER.JS UPDATE INSTRUCTIONS

## Step 1: Add this line after line 4 (after require('dotenv').config();)
```javascript
// Initialize admin user on startup
const { createAdminUser } = require('./scripts/create-admin');
```

## Step 2: Replace the app.listen section (lines 99-102) with:
```javascript
app.listen(PORT, async () => {
  console.log(`Server running on port ${PORT}`);
  
  // Create admin user if it doesn't exist
  try {
    await createAdminUser();
    console.log('Admin user setup completed');
  } catch (error) {
    console.error('Admin user setup failed:', error);
  }
});
```
